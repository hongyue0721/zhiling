## 安装步骤

仓库使用 pnpm 与 `pnpm-lock.yaml`（packageManager `pnpm@11.25.0`）。

```bash
# 0) 环境
node 22.23.2（见 .node-version）
pnpm@11.25.0

# 1) 进入仓库（zhiling）
cd /path/to/zhiling

# 2) 确认基线：应在 dev（8c9d704）或同内容分支
git status --porcelain   # 应为空；若有本地改动请先提交/暂存
git log -1

# 3) 应用 V4 补丁
git apply --check integration/patches/shittim-bookish-v4.patch   # 先预检
git apply integration/patches/shittim-bookish-v4.patch

# 4) 依赖
#    V4 所需字体包与 three/@types/three 仓库中均已存在：
#    @fontsource/allura、@fontsource/fraunces、@fontsource/cormorant-garamond、
#    @fontsource-variable/noto-serif-sc、lxgw-wenkai-screen-web、three、
#    @types/three —— 全部已在 package.json（无版本变更）。
pnpm install              # 仅当锁文件校验需要时；不应新增包

# 5) 验收（与提交时一致）
pnpm format:check
pnpm lint
pnpm typecheck
pnpm architecture
pnpm test:unit
pnpm test:architecture
pnpm test:contracts
pnpm build
```

依赖结论：不需要改动 package.json，也不需要把任何系统字体二进制放进仓库。
本交付包不含 node_modules 与字体文件。
