# 访问控制矩阵

> 状态：强制登录与正式身份解析已由 C1 落地；资源授权细则中标记“提议”或“待决策”的部分仍需评审并随业务接口实施。

## 基本原则

- 认证只证明当前会话对应哪个正式账户，不能代替资源授权；
- 除注册、登录、邮箱验证和显式重发验证邮件外，所有页面、HTTP 接口和 SSE 订阅都默认拒绝未认证访问；一期不提供密码恢复入口；
- 页面重定向只改善体验，Server Component、Route Handler、Server Action 和 SSE 必须各自在服务端验证 Session、`emailVerified=true` 及资源权限；
- 仅知道资源 ID、任务 ID 或分享快照 ID 不能自动获得访问权；
- 受保护内容不得进入未区分账户的公开静态缓存或 CDN 缓存。

服务端入口统一通过 `identity.resolve(headers)` 或 `identity.require(headers)` 取得最小正式身份；产品页面尚未实现，后续页面与业务传输入口必须在自身服务端边界调用该能力，不能只依赖前端重定向。

## 初始矩阵

| 资源或操作 | 未登录访问者 | 任意登录账户 | 所有者或任务参与者 | 说明 |
| --- | --- | --- | --- | --- |
| 注册、登录、邮箱验证与重发验证邮件 | 允许 | 允许 | 不适用 | 仅限 ADR-0010 明确的认证入口；受 Origin、CSRF 与限流保护 |
| 产品首页与精选目录 | 拒绝 | 允许 | 不适用 | 精选内容也不得绕过登录门禁 |
| 精选地图正文与来源 | 拒绝 | 允许 | 不适用 | 仅限已发布版本 |
| 创建自定义生成请求 | 拒绝 | 允许 | 发起者 | 按 Session 账户限频 |
| 生成任务状态与 SSE | 拒绝 | 待决策 | 提议仅任务参与者 | 相同主题执行可复用，不代表任务详情全站公开 |
| 自定义生成地图正文 | 拒绝 | 待决策 | 请求者或已加入学习者 | 需确认是否允许任意登录账户凭 ID 读取 |
| 加入地图 | 拒绝 | 允许 | 当前账户 | 学习关系归当前 Session 账户 |
| 题面读取与提交答案 | 拒绝 | 拒绝他人关系 | 当前学习关系所有者 | 未作答题面不含答案 |
| 学习进度与答题历史 | 拒绝 | 拒绝 | 当前学习关系所有者 | 同时校验身份和资源关系 |
| 实时结课报告 | 拒绝 | 拒绝 | 当前学习关系所有者 | 与分享快照分离 |
| 创建或撤销分享 | 拒绝 | 拒绝 | 报告所有者 | 撤销后立即失效 |
| 读取分享快照 | 拒绝 | 持有有效链接时允许 | 创建者同样凭有效链接 | 继承原分享链接语义，但要求接收者登录 |

## 生成任务复用边界

项目要求相同生成身份的并发请求复用任务，但“复用执行”与“共享授权”必须分开：

- 推荐为每个合法请求账户登记任务参与关系；
- SSE 建连和重连同时校验 Session 与任务参与关系；
- 任务成功后，各参与账户分别建立自己的学习关系；
- 缓存地图可以复用，答题、进度和报告仍归各自账户；
- 直接猜中任务 ID 的其他登录账户不得读取阶段、错误或调用信息。

以上是提议，需与地图缓存可见性共同通过 ADR 确认。

## 分享边界

当前基线采用“有效登录会话 + 不可预测分享链接”共同授权读取快照，不建立指定收件人名单。需要进一步确认：

- 是否显示创建者身份；
- 接收者能否继续转发链接；
- 是否记录访问审计；
- 分享快照和访问记录的保留期限。

如果未来改为指定账户可读，需要新增收件人授权模型和邀请流程，不能在现有链接规则上静默增加判断。

## 实现验证要求

- 对矩阵中的每一行提供未登录、错误账户和合法账户测试；
- 会话过期后，新的 HTTP 请求和 SSE 重连必须重新认证；
- 分享撤销后即使存在应用缓存，也不能继续读取；
- 日志记录拒绝类别和关联 ID，不记录会话令牌或受保护正文；
- OpenAPI 中声明会话安全方案，并区分未认证与无权限响应。
