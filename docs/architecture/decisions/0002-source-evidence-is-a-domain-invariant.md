# ADR-0002：将来源证据作为领域不变量

- 状态：Accepted
- 日期：2026-09-02
- 决策依据：`PROJECT_GOAL.md` 第 1、3、7 和 10 节

## 背景

知径的核心价值不是生成摘要，而是把真实知乎讨论组织成可追溯的学习路径。若来源只作为展示附属字段，模型生成的观点、题目或链接就可能在关系不完整时仍被保存和展示。

## 决策

来源、结构化观点和题目解释之间的证据关系是正式地图成立的必要条件，而不是 UI 层的可选装饰。

- 来源必须由知乎适配器实际取得并校验；
- 模型只能引用任务上下文中提供的来源标识，不能生成 URL；
- 每条观点至少关联一个有效来源；
- 每道题目的答案与解释必须能追溯到所属节点的来源；
- 证据关系或图结构校验失败时，候选地图不得发布；
- 材料不足必须显式表达，不能以模型常识补齐。

## 理由

把证据提升为持久化和发布门禁，才能从数据层保证“所有结论可追溯”，并让接口、页面和测试复用同一个业务事实。

## 替代方案

- 保存模型文本，展示时再尝试匹配来源：会产生无法修复或错误匹配的正式数据。
- 只在提示词中要求模型附带来源：模型约束不是业务完整性保证。
- 缺少来源时隐藏引用区域：掩盖事实缺失，违反产品定位。

## 影响

- 数据模型需要显式的节点来源与观点来源关系；
- 生成流水线需要在发布前验证所有引用；
- 删除、失效或去重来源必须考虑现有证据关系；
- 精选审核可以对相同证据结构进行人工复核。

## 迁移与验证

为来源、观点、题目候选建立运行时 schema 和关系校验测试。集成测试必须覆盖未知来源 ID、模型生成 URL、跨节点引用、材料不足及半成品不得公开读取等失败场景。
