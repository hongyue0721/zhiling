# ADR-0013：学习验证计分与完成规则

- 状态：Accepted
- 日期：2026-09-02
- 决策者：哥哥（鸿岳）

## 背景

一期每个节点提供 2–3 道有来源依据的单选、多选、匹配或观点辨析题。节点完成必须由服务端判题结果驱动，未作答题面不能携带正确答案。若不固定部分得分、及格、重试、并发和版本规则，同一组答案可能在不同入口产生不同进度。

## 决策

### 题目与节点得分

- 每道题在所属节点内等权；
- 单选、匹配和观点辨析只有完全正确才取得该题满分，否则为 0；
- 多选题得分比例为 `max(0, (选中正确项数 - 选中错误项数) / 正确项总数)`，并限制在 0 至 1；未选择得 0；
- 每题比例转换为 0–10000 的整数基点并向下取整；节点成绩为各题基点的算术平均值并向下取整；
- 节点最佳成绩达到 8000 基点（80%）时节点完成。

### 尝试、最佳成绩与并发

- 不限制重试次数，每次提交都形成不可变尝试记录；
- 提交携带作用域限定到当前学习关系和题目集的幂等键，同一键重复提交返回同一判题结果，不创建第二次尝试；
- 最佳成绩只取所有有效尝试的最大值；并列成绩不覆盖首次达到该成绩的尝试引用；
- 判题记录、最佳成绩条件更新和首次完成转换在同一数据库事务中执行；
- 完成状态单向变化，后续低分或并发提交不能把已完成节点改回未完成。

### 版本规则

- 题目集绑定不可变地图版本；修改题面、选项、答案、评分解释或来源关系必须创建新版本，不能覆写既有题目；
- 学习关系继续绑定开始学习时的地图和题目版本；新版本不会重算、抹除或降级既有成绩与完成状态；
- 新建立的学习关系使用当时可选的正式版本；未来若允许用户主动升级版本，必须另行定义迁移规则。

## 理由

80% 阈值保留“学完必须验证”的区分度，无限重试符合低风险学习场景。多选扣除误选可以提供有限部分得分并阻止无成本全选。不可变尝试、幂等提交、最大值条件更新和版本绑定使并发及内容演进具有确定结果。

## 替代方案

- 所有题型全对且节点 100% 才完成：规则简单，但 2–3 题节点容错过低。
- 节点达到 60% 完成：流程更顺滑，但对掌握度的区分较弱。
- 限制尝试次数：更像考试，会阻碍学习型反复练习，且需要额外处理次数恢复和申诉。
- 新题目版本重算历史成绩：会静默改变既有学习事实并破坏报告稳定性。

## 影响

- D2 必须保存不可变尝试、幂等键、题目版本、最佳成绩和首次完成事实；
- 客户端只展示服务端返回的得分与完成状态，不能自行复算或写入；
- E2 私人结课报告引用学习关系绑定版本上的稳定成绩；
- 题目数量少时单题权重较高，但无限重试允许学习者纠正理解。

## 迁移与验证

实现时覆盖单题评分、多选误选扣分、80% 边界、重复幂等提交、并发高低分提交、完成状态单调性和版本隔离。正确答案及评分规则的服务端秘密部分不得进入未作答题面 DTO。
