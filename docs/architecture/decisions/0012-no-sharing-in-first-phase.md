# ADR-0012：一期不实现分享能力

- 状态：Accepted
- 日期：2026-09-02
- 决策者：哥哥（鸿岳）

## 背景

原一期范围包含结课报告的只读分享快照、登录后链接读取和撤销能力。该能力需要额外定义接收者授权、创建者身份展示、转发、访问审计、保留期限及缓存失效规则，但不影响学习地图、来源、答题、进度和私人结课报告构成的核心学习闭环。

## 决策

一期不实现任何分享能力：

- 结课报告只允许所属学习关系的账户读取；
- 不创建分享快照、分享令牌、接收者名单、分享页面或分享 API；
- 不建立分享访问审计、撤销状态和相关缓存失效机制；
- 不把自定义地图 ID、报告 ID 或其他资源 ID 当作跨账户分享凭据；
- 工作包 E2 收敛为“结课报告”，只负责所属账户的报告投影；
- 若未来重新引入分享，必须作为新范围重新确认授权、隐私、审计、保留和撤销规则，不复用本期资源 ID 形成隐式分享入口。

本 ADR 取代 ADR-0007 中关于“分享创建和分享读取属于一期受保护产品能力”的范围描述；ADR-0007 的全产品强制登录原则继续有效。

## 理由

分享不是完成学习闭环的前置。移除它可以避免在没有明确传播和隐私需求时建立一套长期维护的授权与审计模型，同时不削弱私人报告、跨会话恢复和核心学习结果。

## 替代方案

- 任意已验证账户凭不可预测链接读取：实现较简单，但链接转发会扩散访问权，并引入撤销和审计义务。
- 指定账户白名单：隔离更强，但需要邀请、名单维护和收件人生命周期，不符合一期范围。
- 仅生成静态导出文件：仍会产生传播、过期和敏感信息处理问题，不是“无分享”的等价实现。

## 影响

- E2 不再依赖分享接收者决策，只依赖学习验证与进度；
- 数据模型、访问控制、API 和端到端测试不得创建分享相关实体或入口；
- 一期成功标准不再包含分享链接创建、读取和撤销；
- 已有代码和生产数据中没有分享能力，无需迁移或兼容层。

## 迁移与验证

同步项目目标、产品需求、访问控制矩阵、领域契约、工作包与测试说明。关闭分享决策 Issue，并将 E2 的远端范围改为私人结课报告。实现阶段验证错误账户不能读取报告；不为已取消能力创建占位路由、表、测试或空模块。
