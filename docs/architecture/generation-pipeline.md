# 地图生成流程

> 状态：流程阶段、持久化状态机、VPS Docker 运行、租约恢复和 SSE 重连已由 ADR-0004 接受；供应商单次请求参数仍等待 #6 的真实契约。

## 发布原则

地图生成是“候选内容逐步形成，完整校验后一次发布”的流程。阶段进度可以对用户可见，但未经校验的节点和题目不能伪装成正式结果。

## 建议状态机

| 状态 | 含义 | 可持久化正式地图 |
| --- | --- | --- |
| `queued` | 请求已接受，等待取得执行权 | 否 |
| `normalizing` | 规范化主题并计算缓存身份 | 否 |
| `cache_lookup` | 查询相同版本的可复用地图 | 否 |
| `planning` | 生成 3–4 个粗粒度学习方向 | 否 |
| `searching` | 按方向查询并整理真实知乎来源 | 否 |
| `structuring` | 基于来源重建 5–7 个最终节点 | 否 |
| `supplementing` | 仅对材料不足节点补充一次搜索 | 否 |
| `extracting` | 提取有来源关联的观点结构 | 否 |
| `assessing` | 生成有来源依据的客观题候选 | 否 |
| `validating` | 校验图结构、来源、观点和题目不变量 | 否 |
| `publishing` | 在事务边界内持久化完整地图 | 正在进行 |
| `succeeded` | 已得到可读取地图，或命中有效缓存 | 是 |
| `failed` | 已以明确错误终止 | 否 |

除 `succeeded` 和 `failed` 外均为非终态。是否支持用户主动取消不在一期已确认范围内，不能先加入业务语义。

## 关键门禁

### 来源门禁

- 每个引用的来源 ID 必须来自本任务的规范化搜索结果；
- canonical URL、内容类型和必要展示字段通过知乎适配器校验；
- 适配器拒绝的数据不得由模型补造。

### 图结构门禁

- 节点数量符合 5–7 个的一期范围；
- 所有边端点存在、无自环且整体无环；
- 每个节点的学习目标、来源和题目达到确认后的最低要求。

### 证据门禁

- 每条结构化观点至少关联一个有效来源；
- 每道题目答案与解释关联节点已有来源；
- 模型返回的未知 ID、URL 或跨节点引用导致校验失败，而不是静默删除后继续发布。

## 缓存与并发

缓存身份至少由以下事实组成：

```text
normalizedTopic + pipelineVersion + sourceAdapterVersion
```

相同身份的并发生成请求共享一个任务或已发布结果，并通过数据库唯一约束和事务保证。每个主动请求账户按 ADR-0014 原子登记任务参与关系；复用执行不授予未参与账户读取权限。

## 失败分类与重试

- `invalid_topic`：主题无法形成可执行学习目标，不重试；
- `source_unavailable`：知乎接口当前不可用，瞬时失败最多重试 2 次；
- `source_insufficient`：真实材料不足以形成合格地图，不重试；
- `model_unavailable`：模型接口当前不可用，瞬时失败最多重试 2 次；
- `candidate_invalid`：模型候选违反 schema 或证据关系，不重试；
- `generation_timeout`：任务超过 10 分钟硬时限，不重试；
- `internal_failure`：不应向客户端泄露细节的系统错误。

每个外部阶段的自动重试使用指数退避；供应商单次请求时限由 #6 的真实契约确定且不得超过任务剩余时限。稳定错误码、阶段和可重试性由服务端产生，第三方正文不进入 HTTP 或 SSE。

## 恢复与可观察性

- Worker 使用 PostgreSQL 任务租约：60 秒有效期、15 秒心跳，租约失效后由其他 Worker 接管；
- 每个阶段持久化输入和完成事实；接管者从最后一个已完成阶段继续，外部副作用必须具有稳定幂等身份；
- 任务事件按任务内单调序号持久化；SSE 使用 `Last-Event-ID` 重放，历史不可用时先返回完整任务快照；
- 初次连接和每次重连都重新验证 Session 与任务参与关系；
- 单个任务硬时限为 10 分钟，本地校验或数据库步骤单次执行上限为 30 秒；
- `publishing` 在单事务内执行；失败事务不产生正式版本，接管或重试从已验证候选重新发布；
- 日志和指标记录任务关联 ID、阶段、耗时、重试次数和稳定失败类别，不记录供应商敏感正文或其他参与者身份。
