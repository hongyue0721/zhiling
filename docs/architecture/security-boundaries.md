# 安全边界

> 状态：依据项目目标整理的强制规则；具体实现需结合认证框架和部署平台威胁建模。

## 身份与授权

- 用户 ID 只从服务端 Session 解析，写接口不得信任请求体、查询参数或请求头中的用户 ID。
- 所有资源写操作同时校验身份、资源所有权和资源当前状态。
- 除注册和登录入口外，所有页面、HTTP 接口和 SSE 订阅默认拒绝未认证访问。
- 系统不创建匿名学习身份，不提供匿名数据向正式账户迁移的隐式入口。
- 知径认证和知乎开放平台鉴权完全分离，不把第三方凭据绑定到用户 Session。

## 密钥与日志

- 知乎 Access Secret、模型密钥和认证密钥只存在于服务端密钥配置中。
- 密钥不得进入客户端构建产物、HTTP/SSE 响应、数据库、测试快照或日志。
- 日志默认记录内部关联 ID、错误类别和阶段，不记录密码、令牌、完整第三方正文或模型敏感输入。
- 环境变量缺失时启动或相关功能应显式失败，不提供生产默认密钥。

## 内容与模型

- 知乎内容和模型输出均视为不可信输入，进入领域前执行长度、类型、枚举、URL 和关系校验。
- 展示第三方内容时防止脚本注入；不直接信任外部 HTML。
- 模型提示和输出不得获得不需要的用户隐私、认证信息或内部密钥。
- 来源链接只能由知乎适配器提供，不接受模型生成链接。

## 题目与分享

- 未作答题面 DTO 与含答案的服务端模型必须隔离，避免序列化时意外泄露答案。
- 判题、得分和完成状态只在服务端产生。
- 分享使用不可预测标识，已登录接收者只能读取快照投影。
- 撤销是授权状态变化；任何缓存都必须保证撤销后立即不可访问。

## 实施前必须完成

- 对 Better Auth Email & Password 的注册、登录、会话建立和失效行为做真实文档和版本验证；
- 明确 CSRF、Cookie 属性、会话失效和密码策略；
- 明确请求体、主题输入、SSE 连接和生成频率限制；
- 建立依赖审计、密钥扫描和客户端包内容检查；
- 为未登录访问、越权、答案泄露和分享撤销编写集成测试。
