# 数据模型与一致性

> 本文件描述概念模型和不变量，不等同于数据库表设计。字段、索引和迁移将在领域契约确认后设计。

每个核心实体需说明：

- 稳定身份和生命周期；
- 必填业务事实及其来源；
- 实体之间的基数、所有权和删除语义；
- 唯一性、不变量和事务边界；
- 并发冲突、幂等和重试规则；
- 审计、隐私、保留与清理要求。

缺失的必填事实必须显式失败。默认值仅可用于已确认的策略，不得用于伪造实体关系或完成状态。

## 已确认概念关系

- 学习地图包含 5–7 个地图节点；节点之间存在有向先修关系。
- 地图、节点和来源内容独立于用户；多个用户通过学习关系复用同一地图。
- 节点与来源是多对多关系，结构化观点通过观点来源关系保留一个或多个证据。
- 验证题属于节点；题目正文与服务端答案必须具有明确的输出隔离。
- 答题记录不可被客户端改写，节点进度由判题规则推导。
- 分享快照在创建时固化公开内容，与实时进度隔离，并具有可撤销状态。
- 生成任务关联规范化主题、流水线版本和来源适配器版本；只有完整校验通过的地图才能发布。

## 必须通过 ADR 明确的不变量

- 地图版本、再生成和缓存命中的身份规则；
- 节点图无环性及先修关系变更规则；
- 答题计分、节点完成和最佳成绩的冲突规则；
- 匿名与正式账户合并时的幂等键、锁和逐实体冲突策略；
- 分享撤销的事务与缓存失效边界；
- 来源去重身份、保留期限和第三方删除后的处理方式。
