# 领域契约

> 状态：地图版本、生成运行、任务授权、学习计分和一期报告边界已有 Accepted ADR；仍标记“待决策”的细则不能由实现自行假定。

## 学习地图

学习地图是可复用的学习内容，不属于某个学习者。地图包含 5–7 个节点以及节点之间的先修关系。

必须满足：

- 节点引用属于同一地图的稳定标识；
- 先修关系不能引用不存在的节点；
- 正式发布的地图必须形成可学习的有向无环结构；
- 每个节点必须有学习目标和足以支持内容的真实来源；
- 未完成整体校验的生成结果不能作为正式地图读取。
- 地图主题使用稳定 `mapId`，每次发布形成不可变 `versionId`；精选目录显式指向当前发布版本；
- 重新发布只切换精选指针，既有学习关系继续绑定其原 `versionId`，不得被静默迁移；

待决策：节点排序规则、允许的分支宽度以及既有学习关系的显式版本升级规则。地图版本身份与精选重新发布语义已由 ADR-0011 确认。

## 来源与证据

来源是系统通过知乎适配器实际取得并校验的内容引用。结构化观点是从来源材料提取的学习内容，必须通过显式关系关联一个或多个来源。

必须满足：

- 来源 URL 只能来自适配器确认的知乎数据，模型不能创建或改写 URL；
- 观点的每个来源 ID 都必须存在且属于当前生成使用的来源集合；
- 共识与分歧是组织形式，不代表系统宣称绝对真理；
- 分歧必须保留各观点的依据和适用条件；
- 来源不足时不得创建“看起来完整”的无依据观点。

供应方适配层当前仅按官方 `ContentType + ContentID` 派生带类型命名空间的 `sourceId`，并按该 ID 聚合去重；这不等同于领域层的最终规范身份。仍待决策：跨供应方/跨 ContentID 的同内容去重、摘录保存尺度以及第三方内容失效后的展示方式。适配器不得以 URL hash、移除查询参数或其他未决业务规则替代该决策。

## 验证题与作答

题目属于地图节点，题干、选项、答案和解释必须能追溯到该节点来源。

必须满足：

- 一期只支持单选、多选、匹配和观点辨析；
- 浏览器取得的未作答题面不包含正确答案或可直接推导答案的内部字段；
- 服务端完成判题并保存不可变尝试；重复幂等键不得创建第二次尝试；
- 每道题等权；单选、匹配和观点辨析完全正确才得分，多选按 ADR-0013 的误选扣分公式取得部分分；
- 每题基点向下取整，节点分数为题目基点算术平均并向下取整；
- 节点最佳成绩达到 80% 时完成，不限制重试次数；
- 最佳成绩原子取历史最大值，完成状态只能单向成立；
- 题目集绑定不可变地图版本，新版本不得重算或抹除旧学习关系的成绩；
- 题目解释引用的来源必须存在于题目所属节点。

## 用户学习关系与进度

用户通过独立学习关系加入地图，不复制地图正文。节点进度和答题历史属于该学习关系所代表的学习者。

必须满足：

- 所有产品读取和写入都要求正式账户登录，并从服务端身份上下文确定学习者；
- 同一身份与同一地图版本的重复加入不能创建语义重复关系；
- 重新登录后能够恢复其学习关系、节点进度和答题记录；
- 学习关系、答题记录和进度在创建时即归属于唯一正式账户；
- 系统不得创建匿名学习关系或提供事后变更学习数据所有者的合并流程；
- 任务成功或命中缓存时，必须为每个合法请求账户分别建立学习关系；
- 自定义地图只允许具有对应学习关系的账户读取，不提供凭地图 ID 加入或跨账户分享。

## 结课报告

结课报告是所属学习关系的服务端投影，只允许该关系对应的正式账户读取。

必须满足：

- 报告只依据不可变答题尝试、最佳成绩、完成状态和所绑定地图版本生成；
- 错误账户读取时不得暴露报告或学习关系是否存在；
- 一期不创建分享快照、分享令牌、接收者名单、撤销状态或跨账户读取入口；
- 后续若重新引入分享，必须通过新的 ADR 和独立授权模型实现。
