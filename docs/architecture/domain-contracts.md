# 领域契约

> 状态：核心不变量已由项目目标确认；带“待决策”的细则不能由实现自行假定。

## 学习地图

学习地图是可复用的学习内容，不属于某个学习者。地图包含 5–7 个节点以及节点之间的先修关系。

必须满足：

- 节点引用属于同一地图的稳定标识；
- 先修关系不能引用不存在的节点；
- 正式发布的地图必须形成可学习的有向无环结构；
- 每个节点必须有学习目标和足以支持内容的真实来源；
- 未完成整体校验的生成结果不能作为正式地图读取。

待决策：地图版本身份、节点排序规则、允许的分支宽度以及精选地图重新发布语义。

## 来源与证据

来源是系统通过知乎适配器实际取得并校验的内容引用。结构化观点是从来源材料提取的学习内容，必须通过显式关系关联一个或多个来源。

必须满足：

- 来源 URL 只能来自适配器确认的知乎数据，模型不能创建或改写 URL；
- 观点的每个来源 ID 都必须存在且属于当前生成使用的来源集合；
- 共识与分歧是组织形式，不代表系统宣称绝对真理；
- 分歧必须保留各观点的依据和适用条件；
- 来源不足时不得创建“看起来完整”的无依据观点。

待决策：来源规范身份、相同内容的去重规则、摘录保存尺度以及第三方内容失效后的展示方式。

## 验证题与作答

题目属于地图节点，题干、选项、答案和解释必须能追溯到该节点来源。

必须满足：

- 一期只支持单选、多选、匹配和观点辨析；
- 浏览器取得的未作答题面不包含正确答案或可直接推导答案的内部字段；
- 服务端完成判题并记录不可伪造的尝试结果；
- 节点完成状态由判题规则驱动，客户端不能直接写入；
- 题目解释引用的来源必须存在于题目所属节点。

待决策：及格阈值、多选部分得分、重试限制、最佳成绩比较规则和题目版本变化后的历史解释。

## 用户学习关系与进度

用户通过独立学习关系加入地图，不复制地图正文。节点进度和答题历史属于该学习关系所代表的学习者。

必须满足：

- 所有写操作从服务端身份上下文确定学习者；
- 同一身份与同一地图的重复加入不能创建语义重复关系；
- 正式登录后能够恢复其学习关系、节点进度和答题记录；
- 匿名合并必须在数据库事务中完成且可安全重试；
- 合并完成不能留下分别指向匿名身份和正式身份的矛盾活动记录。

待决策：重复学习关系、不同最佳成绩、同时作答和已经合并过的匿名身份分别如何解决冲突。

## 分享快照

分享是创建时生成的只读认知报告快照，不是用户实时数据的公开视图。

必须满足：

- 公开读取仅返回快照明确包含的字段；
- 分享访问不暴露内部用户、会话、进度表或答题明细；
- 撤销后公开读取立即失败；
- 后续学习行为不隐式改变已有快照。

待决策：分享令牌强度与轮换、快照保留期、地图或来源删除后的处理规则。
