# 系统上下文

> 状态：一期运行拓扑已由 ADR-0004 确认；模块实现、部署清单和生产运维门禁随 D1/F 交付。

## 参与者与外部系统

| 参与者或系统 | 与知径的关系 | 信任边界 |
| --- | --- | --- |
| 未认证访问者 | 只能注册或登录 | 不具有任何产品数据访问权限 |
| 登录学习者 | 选择或生成地图、学习、答题、恢复进度和读取本人报告 | 浏览器输入不可信，通过服务端会话识别 |
| 精选内容审核者 | 对预生成地图进行人工检查 | 一期不假定存在面向用户的管理后台 |
| 知乎开放 API | 提供问题、回答、文章和公开信号 | 外部数据不可信，必须经适配器校验与规范化 |
| 模型 API | 规划、整理、提取和生成题目候选 | 输出仅是候选数据，不能生成或替代来源事实 |
| PostgreSQL | 保存业务状态、生成任务、参与关系和执行租约 | 仅服务端访问，事务边界必须对应业务不变量 |

## 运行边界

知径一期采用 Next.js 全栈模块化单体，并部署在自管 VPS 的 Docker 环境。Next.js Web 与生成 Worker 使用同一代码库和镜像、作为独立进程运行，共用 PostgreSQL；进程拆分用于隔离请求生命周期和长任务执行，不建立第二套业务服务边界。

```text
浏览器
  ├─ 页面与地图交互
  ├─ HTTP 请求
  └─ SSE 进度订阅
        ↓
反向代理
  └─ Next.js Web
        ├─ 身份解析与接口校验
        ├─ 应用用例与事务编排
        └─ 领域模块
              ↕ PostgreSQL（状态、事件、租约）
        生成 Worker
          ├─ 生成任务编排
          ├─ 知乎开放 API 适配器
          └─ 模型 API 适配器
```

## 信任边界规则

- 浏览器不得指定需要授权的用户 ID；身份只从服务端 Session 获取。
- 除注册和登录入口外，所有产品页面与业务接口都必须先验证登录状态。
- 模型输出和知乎响应都必须经过运行时 schema 校验，不能直接成为领域实体。
- 正确答案、知乎密钥、模型密钥和内部错误详情不得进入客户端响应或日志。
- 持久化成功不能只表示数据库写入成功，还必须表示地图整体业务校验通过。
- 精选地图的读取路径不得依赖知乎或模型服务实时可用。
