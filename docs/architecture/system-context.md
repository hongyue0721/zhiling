# 系统上下文

> 状态：依据项目目标建立的架构基线；具体部署拓扑仍待 ADR 确认。

## 参与者与外部系统

| 参与者或系统 | 与知径的关系 | 信任边界 |
| --- | --- | --- |
| 未认证访问者 | 只能注册或登录 | 不具有任何产品数据访问权限 |
| 登录学习者 | 选择或生成地图、学习、答题、恢复进度和管理分享 | 浏览器输入不可信，通过服务端会话识别 |
| 精选内容审核者 | 对预生成地图进行人工检查 | 一期不假定存在面向用户的管理后台 |
| 知乎开放 API | 提供问题、回答、文章和公开信号 | 外部数据不可信，必须经适配器校验与规范化 |
| 模型 API | 规划、整理、提取和生成题目候选 | 输出仅是候选数据，不能生成或替代来源事实 |
| PostgreSQL | 保存业务状态、任务和分享快照 | 仅服务端访问，事务边界必须对应业务不变量 |

## 运行边界

知径一期采用 Next.js 全栈单体。单体描述的是部署选择，不意味着所有代码可以互相访问：领域模块仍然拥有独立职责、数据所有权和公开应用契约。

```text
浏览器
  ├─ 页面与地图交互
  ├─ HTTP 请求
  └─ SSE 进度订阅
        ↓
Next.js 服务端边界
  ├─ 身份解析与接口校验
  ├─ 应用用例与事务编排
  ├─ 领域模块
  ├─ 生成任务编排
  └─ 基础设施适配器
        ├─ PostgreSQL
        ├─ 知乎开放 API
        └─ 模型 API
```

## 信任边界规则

- 浏览器不得指定需要授权的用户 ID；身份只从服务端 Session 获取。
- 除注册和登录入口外，所有产品页面与业务接口都必须先验证登录状态。
- 模型输出和知乎响应都必须经过运行时 schema 校验，不能直接成为领域实体。
- 正确答案、知乎密钥、模型密钥和内部错误详情不得进入客户端响应或日志。
- 持久化成功不能只表示数据库写入成功，还必须表示地图整体业务校验通过。
- 精选地图的读取路径不得依赖知乎或模型服务实时可用。

## 尚待部署决策

- 地图生成任务是否能在目标平台的请求生命周期内可靠运行；
- SSE 长连接限制、断线恢复和水平扩展方式；
- 任务租约、超时恢复和并发请求合并由数据库还是外部设施承担；
- 精选地图审核发布入口和权限模型；
- 日志、指标、追踪、备份与灾难恢复要求。
