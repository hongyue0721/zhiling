# Shittim 前端交互重构设计与契约文档

本文档记录基于哥哥提出的深度视觉与交互重构成果。

## 一、品牌与视觉语言
1. **品牌定名**：主体更名为 **Shittim**，标语精简为“把讨论走成一条学会的路”。
2. **博客同款书卷手帐风**（参考 https://hongyue.eu.cc/）：
   - **全面去卡片化**：摒弃四周厚重的大卡片与盒子嵌套，改为纯净纸墨留白、极简细虚线（`1px dashed var(--line)`）分割。
   - **艺术字体**：正文统一采用霞鹜文楷（`LXGW WenKai Screen`），标题与编号统一采用思源宋体（`Noto Serif SC Variable`），辅以优雅衬线品牌字。
   - **暖纸墨色板**：主色赭棕（`#8a4423`）、页面暖米纸（`#f6f1e6`）、卡底纸白（`#fdfaf3`）、完成青黛（`#4a7c59`）、警示朱砂（`#a63a2f`）。

## 二、Three.js 交互粒子系统
1. **全局三维粒子背景（`ThreeParticlesBackground`）**：
   - 暖墨、赭石、青黛与金斑微粒在全屏三维空间中缓缓呼吸漂移。
   - 具备物理弹性模型（Hooke's law + 阻尼），当鼠标经过时粒子受力散开波动，移开后自然弹性复位。
   - 针对自动化测试环境与极简偏好自动降级为单帧渲染，绝不阻塞 CPU。
2. **搜索隐入与粒子加载星盘（`ThreeLoadingOrb`）**：
   - 首页点击搜索后，搜索框顺滑溶解隐入消失。
   - 原地升起 Three.js 粒子加载球，围绕三维螺旋轨道旋转，用户可以用鼠标将粒子打乱扰动，粒子受力飞散并在停止扰动后优雅旋聚恢复原貌。
   - 同步展示实时流程步骤文字与进度指示，生成完成后升起“步入学习地图 ↗”大按钮。

## 三、页面流与交互逻辑
1. **登录流（`/auth`）**：
   - 彻底去除卡片包裹，采用诗笺式极简纸墨排版。
   - 登录成功后，触发平滑上滑渐隐滚动，自然过渡进入主页。
2. **探索首页（`/`）**：
   - 彻底移除原底部三条笨重卡片，页面有且仅有主聚焦区：“感兴趣的学习方向”与胶囊搜索框。
   - 搜索与生成闭环一气呵成。
3. **学习工作区（`/learn/[id]`）**：
   - **无边框全景画布**：移除画布四周多余边框与硬质阴影，星图完全沉浸在纸面与背景粒子之中。
   - **节点放大与问题周围展开**：点击任一节点，画布顺滑聚焦并放大对应节点；节点周围动态生成卫星连线，将对应产生的检验题目以放射状气泡展开在节点四周，点击题目可直接跳转检验。
   - **可隐藏节点汇总侧栏**：提供“收起汇总 ⇥ / 展开 ⇤”控制，内部细分为清晰的三栏：
     - **节点内容**：学习目标与核心概念。
     - **文章概括**：知乎真实讨论观点梳理与来源直达。
     - **答题检验**：内置四题型交互检验与即时评分。
   - **卷轴时间轴模式**：参考博客归档设计，以纵向虚线轴、宋体大序号、青黛完成徽章展示整体知识脉络，最右侧常驻总进度与掌握百分比。
4. **文案人话化与删除解释小字**：
   - 彻底清理全站所有长篇大论的说明废话与学术黑话（如“服务端记录事实一致性”“凭据持久化闭环”等）。
   - 按钮统一改说人话（如“开启学径”、“继续探索”、“开始节点验证”、“提交答案”）。
